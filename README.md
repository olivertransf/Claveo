# Claveo

The official website for [Claveo](https://apps.apple.com/us/app/claveo-music-companion/id6755795790), a complete music practice companion app for iPhone and iPad.

## About

Claveo is a music practice app featuring:
- **Practice Recording**: Record unlimited sessions with crystal-clear audio
- **Advanced Metronome**: Precise tempo control with customizable beat patterns
- **Precision Tuner**: Real-time pitch detection with professional accuracy
- **Music Dictionary**: Searchable database of 650+ music terms and definitions

## Tech Stack

- **Framework**: Svelte
- **Build Tool**: Vite
- **Deployment**: Netlify

- **App**: Swift + SwiftUI
- **Tuna** - Pitch detection library by alladinian (https://github.com/alladinian/Tuna)

## Development

```bash
cd web
npm install
npm run dev    # Development server
npm run build  # Production build
```

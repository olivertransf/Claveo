# Screenshots

Add your app screenshots here. The website expects these filenames:

- `recordings.jpg` - Recordings screen
- `metronome.jpg` - Metronome screen  
- `tuner.jpg` - Tuner screen
- `dictionary.jpg` - Music Dictionary screen
- `recording-details.jpg` - Recording Details screen
- `settings.jpg` - Settings screen

## Image Requirements

- **Format**: JPG or PNG
- **Aspect Ratio**: 9:19.5 (iPhone portrait)
- **Recommended Size**: 750x1624px or higher
- **Quality**: High quality, crisp images

## Tips

- Crop screenshots to remove status bars if desired
- Ensure screenshots are clear and readable
- Use consistent styling (all dark mode or all light mode)
- Optimize file sizes for web (aim for <500KB each)

## Quick Setup

1. Export screenshots from your iPhone/Simulator
2. Name them according to the list above
3. Place them in this `screenshots/` folder
4. The website will automatically display them
